weather_aws_airflow

Temperatura de Buenos Aires, cada día

Un pipeline chico y completo: una API pública, una tabla limpia y una orquestación diaria con Airflow.

PythonpandasApache AirflowOpenWeatherMap API
Ver código en GitHub ↗

Paso a paso

  1. Consultar la API

    Pido el pronóstico de Buenos Aires a OpenWeatherMap en unidades métricas, a partir de una fecha de inicio y por 7 días. La respuesta llega en JSON.

    response = requests.get(api_url)
data = json.loads(response.text)

  2. Armar la tabla

    De cada registro del pronóstico me quedo con dos campos: la fecha y la temperatura. Con eso creo un DataFrame de pandas.

    df = pd.DataFrame({
    'Fecha': [registro['dt_txt'] for registro in data['list']],
    'Temperatura (Celsius)': [registro['main']['temp'] for registro in data['list']],
})

  3. Guardar el resultado

    Escribo la tabla en un CSV, sin el índice de pandas.

    df.to_csv('temperatura_Buenos_Aires.csv', index=False)

  4. Automatizar con Airflow

    Defino un DAG con un PythonOperator que ejecuta la extracción una vez por día. Si la tarea falla, Airflow la reintenta una vez a los 5 minutos.

    default_args = {
    'owner': 'didacus',
    'start_date': datetime(2024, 2, 27),
    'retries': 1,
    'retry_delay': timedelta(minutes=5),
}

dag = DAG('mi_dag', default_args=default_args,
          schedule_interval=timedelta(days=1))

etl_yt

Comentarios de YouTube en un CSV

Extracción paginada de la API de YouTube Data v3, con una tabla de usuarios y comentarios lista para analizar.

PythonYouTube Data API v3pandasApache Airflow
Ver código en GitHub ↗

Paso a paso

  1. Conectarme a la API

    Creo el cliente de YouTube Data API v3 con una clave de API. La clave va en una variable de entorno, nunca escrita en el código.

  2. Recorrer todas las páginas

    La API devuelve hasta 100 comentarios por consulta. Un bucle sigue el token de la página siguiente hasta que no quedan más páginas, y va juntando los usuarios y los textos en dos listas.

    while True:
    comments_response = youtube.commentThreads().list(
        part='snippet', videoId=video_id,
        textFormat='plainText', maxResults=100,
        pageToken=next_page_token).execute()
    # ... agrego usuario y comentario a las listas
    next_page_token = comments_response.get('nextPageToken')
    if not next_page_token:
        break

  3. Armar la tabla y guardarla

    Con las dos listas creo un DataFrame de dos columnas, Usuario y Comentario, y lo escribo en un CSV.

    df = pd.DataFrame({'Usuario': users, 'Comentario': comments})
df.to_csv('comentarios_video.csv')

  4. Programar la ejecución diaria

    Un DAG de Airflow llama al script con un PythonOperator, una vez por día y con un reintento a los 5 minutos si algo falla.

    default_args = {
    'start_date': datetime(2024, 1, 1),
    'retries': 1,
    'retry_delay': timedelta(minutes=5),
}
# schedule_interval=timedelta(days=1)

inflation_rate_project

Inflación global desde el año 2000

Un recorrido completo de punta a punta: limpieza en pandas, PostgreSQL en contenedor, y sincronización a Snowflake con Airbyte. El objetivo fue probar cómo se integran Postgres, Docker, Airbyte y Snowflake.

PythonpandasDockerPostgreSQLAirbyteSnowflakeTableau
Ver código en GitHub ↗Documento completo ↗

Paso a paso

  1. Preparar el entorno

    Creo la carpeta del proyecto en Visual Studio Code y un cuaderno de Jupyter. Actualizo pip e instalo las librerías desde requirements.txt.

    ! pip install --upgrade pip
! pip install -r requirements.txt

  2. Explorar los datos

    Reviso cómo es el conjunto: 196 filas y 47 columnas, 45 de tipo float64 y 2 de tipo object. Busco nulos por columna y encuentro que se concentran antes del 2000. Algunos vienen de hechos históricos, como Ucrania, que aparece como Estado independiente tras la disolución de la Unión Soviética. Otros vienen de países que no compartieron sus datos. Decidí no imputar ningún valor.

    infl_dt.shape            # (196, 47)
infl_dt.isnull().sum()   # nulos por variable

  3. Transformar: años en una sola columna

    Con melt() convierto las columnas de años en filas: cada fila queda con país, indicador, año e inflación. Después renombro las columnas.

    infl_dt_1 = pd.melt(infl_dt,
    id_vars=['country_name', 'indicator_name'],
    value_vars=years, var_name='Year', value_name='Inflation')

  4. Transformar: separar por continente

    Armo una lista de países por continente y filtro con isin(). A cada tabla le agrego una columna Continent y la guardo como CSV.

    infl_dt_1_as = infl_dt_1[infl_dt_1['Country'].isin(country_asia)]
infl_dt_1_as['Continent'] = 'AS'

  5. Unir y guardar

    Junto las cinco tablas en una sola y la guardo como inflation_data.csv. Es la etapa de carga de la primera parte del ETL.

    inflation_data = pd.concat(data_frames, ignore_index=True)
inflation_data.to_csv('./csv/inflation_data.csv')

  6. Desplegar PostgreSQL con Docker

    Escribo un archivo postgres_docker.yml con la imagen de PostgreSQL, el puerto 5432 y un volumen para persistir los datos y compartir los CSV. Lo levanto con Docker Compose, entro al contenedor con psql y creo dos bases de datos: INFLATION_GLOBAL con una tabla, e INFLATION_CONTINENT con una tabla por continente. Cargo cada CSV con \COPY.

    services:
  postgres:
    image: postgres:latest
    container_name: inflation_postgres
    ports:
      - "5432:5432"
    volumes:
      - pgdata:/var/lib/postgresql/data

-- dentro de psql
CREATE DATABASE INFLATION_GLOBAL;
\COPY infl_global FROM './inflation_csv/inflation_data.csv' DELIMITER ',' CSV HEADER;

  7. Preparar Snowflake

    Abro una cuenta de prueba de Snowflake y ejecuto el script que propone Airbyte. Lo adapto para crear mi propio rol, usuario, warehouse, base de datos y schema, que van a recibir los datos sincronizados.

  8. Levantar Airbyte

    Descargo el repositorio de Airbyte, ejecuto su script de instalación y entro a la plataforma en localhost:8000. Docker descarga y arranca los contenedores necesarios.

    git clone --depth=1 https://github.com/airbytehq/airbyte.git
cd airbyte
bash run-ab-platform.sh

  9. Conectar PostgreSQL con Snowflake

    En Airbyte creo una conexión nueva. Como fuente elijo PostgreSQL, con los datos del contenedor. Como destino elijo Snowflake, con el host, warehouse, rol, base de datos, schema y usuario que configuré antes. Dejo la programación en manual y ejecuto la primera sincronización.

  10. Verificar el resultado

    En Snowflake abro la base de datos y compruebo que el schema INFLATION_GLOBAL y la tabla INFL_GLOBAL tienen todos los datos. Después repito la sincronización con las tablas por continente.

forestation_proyect

Superficie forestal del mundo

Mismo método que el proyecto de inflación, aplicado a datos de superficie forestal: exploración, limpieza, separación por continente y carga a la nube.

PythonpandasDockerPostgreSQLAirbyteSnowflake
Ver código en GitHub ↗

Paso a paso

  1. Preparar el entorno

    Cuaderno de Jupyter en Visual Studio Code, con pip actualizado y las librerías instaladas desde requirements.txt.

    ! pip install --upgrade pip
! pip install -r requirements.txt

  2. Explorar los datos

    Reviso el conjunto: 7.846 filas y 4 columnas, los tipos de datos y los nulos por variable.

    fo_re.shape            # (7846, 4)
fo_re.isnull().sum()   # nulos por variable

  3. Entender los nulos

    Los valores nulos corresponden a la abreviatura (código) de continentes y regiones, que no existe para esas filas. Es un caso de datos que faltan por su propia naturaleza, no al azar. No imputo nada: al separar por continente esas filas quedan afuera.

  4. Filtrar desde el año 2000

    Me quedo con los registros del año 2000 en adelante.

    fo_re_1 = fo_re[(fo_re['Year'] >= 2000)]

  5. Separar por continente

    Armo una lista de países por continente, filtro con isin() y agrego una columna Continent a cada tabla. Cada una se guarda como CSV.

    fo_re_as = fo_re_1[fo_re_1['Entity'].isin(country_asia)]
fo_re_as['Continent'] = 'AS'

  6. Unir y guardar

    Junto las cinco tablas en una sola y la guardo como forest_area_world.csv.

    forest_area_world = pd.concat(data_frames, ignore_index=True)
forest_area_world.to_csv('forest_area_world.csv')

  7. Cargar a PostgreSQL y a Snowflake

    Levanto PostgreSQL en Docker con un archivo postgres_docker.yml, que comparte la carpeta del proyecto con el contenedor, y sincronizo las tablas hacia Snowflake con Airbyte.
